# Saurav Singh Sisodiya - Data Engineer Portfolio

This is the source code for my personal portfolio website, showcasing my experience, skills, and projects as a Data Engineer.

## 🚀 Features

- Responsive design that works well on desktop, tablet, and mobile devices
- Dark/light mode toggle with user preference saved in local storage
- Optimized performance with lazy-loaded images and code minification
- Clean, modern UI with smooth animations and transitions
- Accessibility compliant with proper ARIA attributes and semantic HTML
- SEO optimized with structured data, proper meta tags, and a sitemap

## 🛠️ Technologies Used

- HTML5
- CSS3 (with CSS variables for theming)
- JavaScript (ES6+)
- jQuery
- Bootstrap 4
- Isotope.js for filtering projects
- Intersection Observer API for lazy loading and animations

## 🖥️ Local Development

To run this website locally:

1. Clone the repository:
   ```
   git clone https://github.com/saurav-singh-sisodiya/saurav-singh-sisodiya.github.io.git
   ```

2. Navigate to the project directory:
   ```
   cd saurav-singh-sisodiya.github.io
   ```

3. Open `index.html` in your browser or use a local server.

## 📝 Performance Optimizations

The website includes several performance optimizations:

- CSS and JavaScript minification
- Lazy loading of images using Intersection Observer API
- Preloading of critical resources
- Optimized font loading
- Reduced render-blocking resources
- Efficient CSS with minimal redundancy

## 🎨 Customization

The site uses CSS variables for easy theming. You can modify the main colors by editing the variables in the `custom.css` file:

```css
:root {
  --primary-color: #4db8ff;
  --primary-hover: #ffc200;
  --dark-bg: #20232a;
  --light-bg: #ffffff;
  --dark-text: #333333;
  --light-text: #ffffff;
  --transition-speed: 0.3s;
}
```

## 📱 Responsive Design

The website is fully responsive with breakpoints for:
- Mobile: < 768px
- Tablet: 768px - 991px
- Desktop: > 992px
